# G-SMAİL 1.2.34

G-SANTRAL İŞ ÇÖZÜMLERİ’nin Türkçe masaüstü e-posta uygulaması.

## 1.2.34 ile gelenler

- cPanel ve Zimbra hesapları otomatik kurulumla başlar. E-posta adresinizin alan adına göre yayımlanmış sunucu, port ve güvenli bağlantı ayarları bulunarak doldurulur.
- Gelişmiş alanlarda yaptığınız değişiklikler korunur. Otomatik doldur düğmesi yayımlanmış ayarları yeniden getirir; giriş reddedildiğinde mevcut alanlar boşaltılmaz.
- Güvenli hesap keşfine STARTTLS desteği eklendi. Parolanız yapılandırma isteğine eklenmez ve sertifika doğrulaması korunur.

## Hangi dosya?

| Dosya | Kullanım |
|---|---|
| G-SMail-Setup.exe | Windows 64 bit için önerilen kurulum ve güncelleme. |
| G-SMail-Portable.exe | Windows’ta tek dosyadan kurulumsuz açılış. |
| G-SMail-1.2.34-linux-amd64.deb | Ubuntu, Mint, Debian ve Pardus 64 bit için önizleme. |
| G-SMail-1.2.34-linux-x64.tar.gz | Linux 64 bit taşınabilir önizleme. |
| SHA256SUMS.txt | Bu sürümün dört indirme paketine ait SHA-256 bütünlük değerleri. |

Güncellemeden önce G-SMAİL’den çıkın. Windows kurulumunu eski sürümü kaldırmadan yapabilirsiniz. Mevcut profil korunur. Portable seçeneği aynı Windows kullanıcısının posta profilini kullanır.

Linux paket içeriği doğrulandı; gerçek Linux masaüstünde çalışma testi henüz yapılmadı.
